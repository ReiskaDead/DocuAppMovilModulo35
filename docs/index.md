# 📱 Portal Oficial de Documentación - Aplicación Móvil

Bienvenido al portal técnico y de usuario del proyecto móvil desarrollado para el **Módulo 3.5 y 3.4**. Este sitio reúne de manera centralizada la arquitectura, especificaciones de la API, guías de despliegue con Docker y políticas de seguridad del sistema bajo el estándar **Docs-as-Code**.

---

## 🎯 Objetivo del Proyecto
Proporcionar una solución móvil robusta, segura y escalable que permita la interacción fluida entre los usuarios y los servicios centrales mediante consumo de servicios REST API.
